About the book

One sunrise, one lesson, one little animal

Each story follows an animal with its own psychology and a human value to nurture: faith, discipline, unity, solidarity, patience, respect, love, and family. Written to be read before bed, every story closes with the same wish: sweet dreams.

Created by Ania Vallejo Placeres, meant to awaken the inner child we all carry.
